O **TruckPay** é o projeto flagship da **Sicks Tech**. Trata-se de um sistema mobile de ponto de venda (mPOS) desenvolvido nativamente para Android, projetado especificamente para operações de Food Trucks, comércio móvel e automação comercial de rua.

O app transforma qualquer smartphone ou terminal SmartPOS em uma solução de pagamento completa, focada em **velocidade, segurança e estabilidade** em cenários reais de alta demanda.

---

## 📱 Sobre o Projeto

Diferente de sistemas genéricos, o TruckPay foi construído com a filosofia **software-first**. Isso significa que priorizamos fluxos de venda intuitivos e uma arquitetura robusta preparada para falhas de rede e uso intenso em balcão.

### 🎯 Principais Diferenciais
* **Fluxo de Venda Simplificado:** Interface otimizada para o "corre" do dia a dia, com componentes grandes e de fácil toque.
* **Pagamentos Integrados:** Suporte nativo para transações via cartão (mPOS) e PIX.
* **Domínio de Hardware:** Integração profunda via SDK com terminais POS e comunicação direta com impressoras térmicas (**protocolo ESC/POS**).
* **Resiliência:** Preparado para operar de forma eficiente mesmo com instabilidade de conexão.
* **Gestão Real-time:** Acompanhamento de transações e histórico de vendas direto no dispositivo.

---

## 🛠 Stack Técnica & Engenharia

Seguimos um padrão de desenvolvimento rigoroso para garantir que o software seja leve e de fácil manutenção:

* **Linguagem:** Kotlin (Nativo).
* **Arquitetura:** MVVM (Model-View-ViewModel) com separação clara de responsabilidades.
* **Persistência de Dados:** Room Database com cache inteligente para operações offline.
* **Comunicação:** Retrofit + Coroutines para integração assíncrona com APIs REST.
* **Interface:** Material Design, ViewBinding e ConstraintLayout para máxima performance de renderização.
